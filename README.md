O New Perssua é um aplicativo de overlay para desktop que permite visualizar notas, roteiros ou auxílios de IA em tempo real, permanecendo completamente invisível para outras pessoas durante compartilhamentos de tela. Utilizando APIs nativas de proteção de conteúdo do Windows e macOS, o sistema garante privacidade total em reuniões, entrevistas técnicas, apresentações ou transmissões ao vivo, sem interferir no foco da janela principal.
